# きっかけ 仕様 v2.2.3

## コンセプト
3ステップで誰でも作れる、一番やさしい自動化アプリ。Trigger→Action→Constraint を、日本語＋色分けブロックで再構成する。キャッチフレーズ「きっかけを置くだけで、スマホが動く。」質感は Liquid Glass（Simple Glass スキルの読み物ガラス数値に準拠。詳細は ART_DIRECTION.md v2.1）。

## 画面
1. 初回オンボーディング（8ページ：フック→困りごとの3択→ぴったり宣言→ステップ紹介3→試し操作→接続）。試しを置いた直後の最終ページで、その自動化に必要な許可だけをその場で案内する
2. ホーム：自動化一覧（ON/OFF、テスト実行、編集、削除＋取り消し、最終実行表示）、最近の実行（成功・失敗とも直近5件表示、一覧の直下）、権限チェック（必要な分だけ、その下）、テンプレ8件（自動化があると折りたたみ）、FAB「＋ つくる」
3. 作成ウィザード：Step1 きっかけ / Step2 やること（複数選択、4グループ表示） / Step3 名前＋条件＋プレビュー。アプリ選択は独立画面。必須のアプリ選択が済むまで保存不可
4. ダークモード：端末設定に追従

## きっかけ（Trigger）
時刻（正確なアラーム、曜日指定可） / 日の出・日の入り（アラーム、登録地点から計算） / 場所：着いたら・離れたら（約15分間隔、半径200m） / Wi-Fiにつながったら（約15分間隔、接続エッジ検出） / Bluetooth接続（即時） / ヘッドホン（有線のみ・即時） / 充電が始まったら（即時） / ケーブルを抜いたら（即時） / 電池が少ない・増えたら（約15分間隔、しきい値crossing検出） / アプリを開いたら・閉じたら（使用状況アクセス、約15分間隔検出） / 通知が来たら（通知アクセス、即時、アプリ＋キーワード指定） / 集中モード・省電力・機内モード（状態変化のエッジ検出）。きっかけは全16種、作る画面では7ジャンル（時刻／場所／つながり／充電・電池／アプリ／連絡／端末の状態）の見出しで整理する。全パターンにアイコン（絵文字）を持ち、選択画面とカードのチップに表示する

## やること（Action・複数選択可・9グループ・全38種）
- 知らせる：通知を出す / 声で知らせる（TTS） / 音を鳴らす / バイブする / ウィジェットに表示（ホーム画面ウィジェットの文字を差し替え）
- AI：AIに聞く（端末内AI＝Gemini Nano を優先、ダメならホームの「AIに聞く の設定」で入れたキーで Gemini API。答えは通知で出し、変数 {ai} で後続の動作にも渡せる）
- 音：音楽を再生／停止 / 音楽を再生（再生だけ） / 次の曲へ / 音量を上げる / 音量を下げる / マナーモード / マナーモードを解除 / おやすみモード / おやすみモードを解除
- 画面・ライト：明るさを下げる / 明るさを戻す / ライト（トグル）
- 設定を変える：画面回転を固定 / 画面回転を自動に / 画面を消さない（自動消灯オフ／戻す・切替） / 壁紙を変える / Wi-Fi設定を開く / Bluetooth設定を開く
- 送る・開く：URLを開く / 動画を再生 / プレイリストを再生 / カメラを開く（自動撮影はAndroidの制限で不可） / テキストを共有 / メッセージ作成を開く
- 記録する：予定を追加 / メモを保存 / コピーする / 現在地を知らせる / 天気を知らせる
- その他：少し待つ / アプリを起動する
- 上級者向け：Webに送る（GET） / 直前を繰り返す / コマンド実行（/system/bin/sh、出力を通知・15秒まで） / JavaScript実行（Rhino解釈モード、printと最後の値を通知）

## 条件（Constraint・任意）
条件なし / 平日だけ（月〜金） / 夜だけ（21時〜翌6時）。テスト実行では条件を外して実行し、結果を必ず言葉で返す（一部だけ動いた場合はその旨も伝える）

## 実行エンジン
- テスト実行：条件を外して即実行、結果（動いた／一部だけ動いた／許可不足）をトーストで返す。完了待ちのある動作（声で知らせる）のためバックグラウンドで実行する
- 実発火：時刻・日の出入り＝AlarmManager（正確なアラーム許可があれば exact）、充電開始・ケーブルを抜く・ヘッドホン・Bluetooth接続・機内モード・省電力＝Manifestレシーバー（即時、goAsyncでバックグラウンド実行）、通知が来たら＝通知リスナーサービス（即時）、電池・Wi-Fi・アプリ開閉・場所・端末状態＝WorkManager 約15分間隔チェック（状態きっかけはレシーバーと併用し、初回観測では発火しない）
- 声で知らせる：TTSの初期化と発声完了まで待ち、実際に声が出た時だけ成功とする
- 再起動：BootReceiver でアラーム再登録と定期チェック再開
- 権限不足の動作は実行せず、ホームの「権限チェック」（その許可が要る自動化がある時だけ表示）へ誘導
- 実行履歴：成功・失敗（理由つき）とも直近20件まで端末内に記録し、ホームに5件表示

## 永続化
SharedPreferences + JSON（v0.2以前の単一アクション形式からの自動移行つき）。外部送信なし。

## 未対応
場所トリガー、変数・条件分岐の高度な編集

## v1.5.0 初心者レビュー対応（B-1〜B-12）
- 通知を出す／声で知らせるは、Step2で文を書ける（空なら「『名前』を実行しました」）。要約にも文を表示。
- 保存・テンプレ追加の直後、不足している許可があれば案内ダイアログを出す。許可行には「行き先で何をするか」の一言を追加。
- ホーム右上に「使い方」画面（3ステップ＋困ったときは）。
- オンボーディング完了文を事実に合わせて修正（試していない場合はテンプレへの案内）。
- 時刻の分は5分刻み（0〜55）。アプリ選択に検索欄とアイコンを追加（上限200件）。
- 電池・Wi-Fi・アプリ起動の遅延注意をテンプレとカードにも表示。失敗理由は「平日だけ／夜だけの条件に合わなかった」と具体化。
- カードのスイッチに「オン／オフ」ラベル。テスト結果はスナックバーで残す。
