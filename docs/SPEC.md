# きっかけ MVP仕様 v0.1.0

## コンセプト
3ステップで誰でも作れる、一番やさしい自動化アプリ。MacroDroid風の Trigger→Action→Constraint を、日本語＋色分けブロックで再構成する。

## 画面
1. ホーム：自動化一覧（ON/OFF、テスト実行、削除、最終実行表示）、テンプレ4件、FAB「＋ つくる」
2. 作成ウィザード：Step1 きっかけ / Step2 やること / Step3 名前＋条件＋保存。全画面 BackHandler 付き
3. テンプレはホーム内セクションとして提示

## きっかけ（Trigger）
時刻 / 電池が少なくなったら / Wi-Fiにつながったら / 充電が始まったら / アプリを開いたら

## やること（Action）
通知を出す / 音量を変える / 明るさを下げる / マナーモード / アプリを開く / ライトをつける

## 条件（Constraint・任意）
条件なし / 平日だけ / 夜だけ

## 実行エンジン（v0.1の割り切り）
- テスト実行ボタン：全アクション即実行可能（デモの核）
- 実発火：電池低下・充電開始は BroadcastReceiver で監視。時刻は AlarmManager で簡易予約
- Wi-Fi／アプリ起動トリガーは v0.1 では保存とテスト実行のみ（実発火は次版）
- 明るさ・マナーモードは端末権限がない場合トーストで案内し、落とさない

## 永続化
SharedPreferences + JSON。Roomは使わない。

## 未対応
