# きっかけ 仕様 v1.2.0

## コンセプト
3ステップで誰でも作れる、一番やさしい自動化アプリ。Trigger→Action→Constraint を、日本語＋色分けブロックで再構成する。キャッチフレーズ「きっかけを置くだけで、スマホが動く。」

## 画面
1. 初回オンボーディング（8ページ：フック→困りごとの3択→ぴったり宣言→ステップ紹介3→試し操作→接続）
2. ホーム：自動化一覧（ON/OFF、テスト実行、編集、削除＋取り消し、最終実行表示）、最近の実行（履歴5件）、権限チェック（必要な分だけ、一覧の下）、テンプレ6件（自動化3件以上で折りたたみ）、FAB「＋ つくる」
3. 作成ウィザード：Step1 きっかけ / Step2 やること（複数選択） / Step3 名前＋条件＋プレビュー。アプリ選択は独立画面。必須のアプリ選択が済むまで保存不可
4. ダークモード：端末設定に追従

## きっかけ（Trigger）
時刻（正確なアラーム） / 電池が少ない（約15分間隔チェック、しきい値crossing検出） / Wi-Fiにつながったら（約15分間隔、接続エッジ検出） / 充電が始まったら（即時） / 充電が終わったら（ケーブルを抜いたら・即時） / ヘッドホンをつないだら（有線・即時） / アプリを開いたら（使用状況アクセス、約15分間隔検出）。全パターンにアイコン（絵文字）を持ち、選択画面とカードのチップに表示する

## やること（Action・複数選択可）
通知を出す / 声で知らせる（TTS） / 音を鳴らす / 音楽を再生／停止 / 次の曲へ / 音量を上げる / 音量を下げる / 明るさを下げる / 明るさを戻す / マナーモード / マナーモードを解除 / おやすみモード（通知を全部止める） / バイブする / アプリを起動する / ライト（トグル）

## 条件（Constraint・任意）
条件なし / 平日だけ（月〜金） / 夜だけ（21時〜翌6時）。テスト実行では条件を外して実行し、結果を必ず言葉で返す。

## 実行エンジン
- テスト実行：条件を外して即実行、結果（動いた／許可不足）をトーストで返す
- 実発火：時刻＝AlarmManager（正確なアラーム許可があれば exact）、充電＝Manifestレシーバー（即時）、電池・Wi-Fi・アプリ起動＝WorkManager 約15分間隔チェック
- 再起動：BootReceiver でアラーム再登録と定期チェック再開
- 権限不足の動作は実行せず、ホームの「権限チェック」（その許可が要る自動化がある時だけ表示）へ誘導
- 実行履歴：成功した実行を直近20件まで端末内に記録し、ホームに5件表示

## 永続化
SharedPreferences + JSON（v0.2以前の単一アクション形式からの自動移行つき）。外部送信なし。

## 未対応
