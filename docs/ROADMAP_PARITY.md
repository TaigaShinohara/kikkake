# iOSショートカット同等化ロードマップ（2026-11-22 本人決定）

本人の決定：「あっちでできることは全部できるようにしたい。ただし複雑そうに見せたくないから、同じジャンルで一つにまとめたり、上級者向けとして隠したりしてシンプルさを維持して」

## 見せ方の原則（シンプルさの維持）
- きっかけ・やることは**ジャンルでまとめる**。ジャンルを選ぶと中身が開く（段階表示）。
- 上級者向け（分岐・繰り返し・変数・Web/API・NFC等）は、作る画面の下に**畳んだ状態**で置く。開かない人には存在が見えない。
- 既定の3ステップとホームの見た目は変えない。増えるのは「選べる中身」だけ。

## きっかけのジャンル設計（7種 → 7ジャンル・約20種）
| ジャンル | 中身（★=新規） |
|---|---|
| 時刻 | 時刻（曜日指定★）、日の出・日の入り★ |
| 場所 | 着いたら★、離れたら★（ジオフェンス） |
| つながり | Wi-Fi（名前指定★）、Bluetooth接続★、NFCタグ★（上級者向け） |
| 充電・電池 | 充電開始、ケーブルを抜いたら、電池が少ない、電池が増えたら★ |
| アプリ | 開いたら、閉じたら★ |
| 連絡 | 通知が来たら★（アプリ・キーワード指定。メール/メッセージ/支払い通知もここで近似） |
| 端末の状態 | 集中モード★、省電力モード★、機内モード★、ヘッドホン |

## やることのジャンル設計（16種 → 約30種＋上級者向け）
| ジャンル | 中身（★=新規） |

| 知らせる | 通知、声、音、バイブ（現行） |

| 送る・開く | アプリ起動（現行）＋URLを開く★、共有を開く★、メッセージ作成を開く★ |
| 記録する | カレンダーに追加★、メモをファイルに保存★、クリップボードにコピー★、現在地を通知★、天気を通知★ |
| 上級者向け（畳む） | 少し待つ★、もし〜なら（分岐）★、繰り返し★、Webリクエスト（GET/POST・JSON）★、変数★ |

## 段階計画
- **Phase 1（v1.8.0）きっかけ拡充【完了 2026-11-22】**：きっかけ7種→16種（日の出・日の入り／場所／Bluetooth／通知が来たら／アプリを閉じたら／電池が増えたら／集中モード／省電力／機内モード＋時刻の曜日指定）。ジャンル見出しのUIも導入済み。場所、Bluetooth、集中モード、省電力、機内モード、通知が来たら、アプリを閉じたら、電池が増えたら、時刻の曜日指定、日の出・日の入り。ジャンルまとめのUIもここで導入。
- **Phase 2（v1.9.0）やること拡充【完了 2026-11-22】**：やること16種→27種（設定を変える5／送る・開く3／記録する5／少し待つ）。設定を変える／送る・開く／記録する の各ジャンル、「少し待つ」。
- **Phase 3（v2.0.0）上級者向け【完了 2026-11-22】**：分岐はツリーではなく条件の上級化（電池◯%以上／ネット接続中だけ／充電中だけ）で近似、繰り返し（直前を繰り返す）、変数（{date}{time}{weekday}{battery}）、Webリクエスト（GETのみ）、NFC（アプリを開いてかざす方式）、自動化の書き出し/読み込み（JSON共有・貼り付け）。上級者向けはウィザードで折りたたみ表示。

## Androidの制約で「そのまま」できないもの（正直な線引き）
- アラームを止めたら／睡眠・起床／ワークアウト開始：他社アラームや健康データのリアルタイム検知に公開APIがない → 不可（将来も見込み薄）。
- SMSの自動送信：Playポリシーで強く制限 → 「メッセージ作成を開く」まで。
- Wi-Fi／Bluetoothの完全なON/OFF：Android 10/13以降、一般アプリからは切替不可 → 設定パネルを開く形で代替。
- Apple Payの取引：Androidに無い → 支払い系アプリの通知を「通知が来たら」で拾う近似。
- CarPlay：Android Auto接続 ≒ 車のBluetooth接続で代替（Phase 1のBluetoothに含む）。
