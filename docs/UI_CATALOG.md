# きっかけ UIカタログ v1.0

| パーツ | 役割 | 使う場面 | 狙い |
|---|---|---|---|
| MacroCard | 自動化1件の表示 | ホーム一覧 | きっかけ→やることが一目で分かる |
| TriggerChip / ActionChip | 選択肢カード | ウィザードStep1/2 | 色で役割を伝え、タップだけで選べる |
| StepHeader | 進捗表示 | ウィザード上部 | 今どこにいるか迷わせない |
| TemplateCard | テンプレ提示 | ホーム下部 | ゼロから考えなくても始められる |
| EmptyState | 空状態 | ホーム（0件時） | 不安にさせず次の一歩を示す |
| ConstraintChip | 条件選択 | ウィザードStep3 | 任意であることを軽く伝える |

新規パーツは狙いを添えてここへ登録してから完了とする。

## 追加パーツ（v1.0〜v1.1）
| パーツ | 狙い |
|---|---|
| オンボーディング（8ページ） | 1ページ1主張で「何のアプリか→困りごと選択→ぴったり宣言→3ステップ→試し操作→接続」。試し操作は選んだ困りごとに対応するテンプレを出す |
| 権限チェック（必要連動型） | その許可が要る自動化がある時だけ、一覧の下に出す。主役（一覧）を奪わない |
| アプリ選択画面 | ウィザードから独立した全画面リスト。スクロールの競合を避ける |
| 最近の実行 | 発火した証拠をホームで見せる（直近5件）。「動いた」実感の着地点 |
| 削除スナックバー | 削除直後に「元に戻す」を出す。誤タップから作品を守る |
| 保存ハイライト | 新しく作ったカードを淡ピンクで目立たせ、そこへスクロールする。作れた手応えを作る |
