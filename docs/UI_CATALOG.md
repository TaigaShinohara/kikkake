# きっかけ UIカタログ v1.4

| パーツ | 役割 | 使う場面 | 狙い |
|---|---|---|---|
| MacroCard | 自動化1件の表示 | ホーム一覧 | きっかけ→やることが一目で分かる |
| TriggerChip / ActionChip | 選択肢カード | ウィザードStep1/2 | 色で役割を伝え、タップだけで選べる |
| StepHeader | 進捗表示 | ウィザード上部 | 今どこにいるか迷わせない |
| TemplateCard | テンプレ提示 | ホーム下部 | ゼロから考えなくても始められる |
| EmptyState | 空状態 | ホーム（0件時） | 不安にさせず次の一歩を示す |
| ConstraintChip | 条件選択 | ウィザードStep3 | 任意であることを軽く伝える |

新規パーツは狙いを添えてここへ登録してから完了とする。

## 追加パーツ（v1.0〜v1.1）
| パーツ | 狙い |
|---|---|
| オンボーディング（8ページ） | 1ページ1主張で「何のアプリか→困りごと選択→ぴったり宣言→3ステップ→試し操作→接続」。試し操作は選んだ困りごとに対応するテンプレを出す |
| 権限チェック（必要連動型） | その許可が要る自動化がある時だけ、一覧の下に出す。主役（一覧）を奪わない |
| アプリ選択画面 | ウィザードから独立した全画面リスト。スクロールの競合を避ける |
| 最近の実行 | 発火した証拠をホームで見せる（直近5件）。「動いた」実感の着地点 |
| 削除スナックバー | 削除直後に「元に戻す」を出す。誤タップから作品を守る |
| 保存ハイライト | 新しく作ったカードを淡ピンクで目立たせ、そこへスクロールする。作れた手応えを作る |

## パターンのアイコン（v1.2）
全てのきっかけ・やることに絵文字アイコンを1つ割り当てる。狙い：文字を読まなくても、アイコン＋短い名前で一覧を判別できるようにする。選択画面（ウィザードStep1/2）とホームのカードのチップに同じアイコンを出す。

## 追加・変更（v1.4）
| パーツ | 狙い |
|---|---|
| Step2 グループ見出し | やること16種を「知らせる／音／画面・ライト／その他」に分ける。15種のフラット一覧で「設定画面みたいな難しさ」にならないため。「音」グループには静かにする系の違い（マナーモード＝着信音／おやすみ＝通知全部）の一言を添える |
| 試し直後の許可案内カード | オンボーディング最終ページで、試しの自動化に必要な許可だけをその場で案内する。初回の発火を無言で失敗させないため |
| 失敗の実行表示 | 最近の実行に、失敗した実行も理由つき（⚠ …許可が足りないので動かなかった）で出す。「動いていない」ことに気づけるようにするため |
| 最近の実行の配置 | 一覧の直下（権限チェックより上）。発火確認の着地点を主役の近くに保つため |

## 追加（v1.4.1・Simple Glass 全面適用）
| パーツ | 狙い |
|---|---|
| PrimaryButton | 主ボタンの共通形。役割色ベタ＋やんわりグラデーション（白+8%→黒-4%）、押すと少し沈む。無効時は淡色＋補助文字色で「押せない」が一目で分かる |
| pressable | カード型タップ対象の共通フィードバック（押した瞬間に0.98倍）。状態の完全性のため |
| solidBrush / tintBrush | 面のグラデーションの正本適用（ベタ／ティント）。glass() も透過色に±4ptの段を持つ |
| 文字階層 | 28（タイトル）／24（大見出し）／18（見出し）／15（本文・行間24）／13（小）の5階層だけを使う |
| InputFace | 名前入力の面（白84%／ダーク20%、角丸24、フォーカスでふちがピンク） |
