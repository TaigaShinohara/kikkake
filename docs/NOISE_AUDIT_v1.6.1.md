# ノイズ監査 v1.6.1 → v1.7.0（2026-11-22）

本人の指示「アプリ全体のノイズを消して」を受け、minimal_information_design スキルの手順（コンセプト仕分け → 対照表 → ノイズ消し → 重複排除）で全画面を棚卸しした記録。

## 判定軸（コンセプト、正本 SPEC）

「自動化に詳しくない人が、日常の場面で、きっかけ→やること→条件の3ステップで自動化を作ることで、読まなくても作れて、動いて安心できる」
要素：誰＝詳しくない人／場面＝日常の自動化ニーズ／行為＝3ステップで作る／状態＝迷わず作れる・動いて安心／価値＝一番やさしい。

## 対照表（同じレイヤー同士で見比べた結果）

### 必須＋支援（残したもの、抜粋）
- ホーム：タイル（名前・要約・スイッチ・テスト/編集/削除）、最近の実行（「動いて安心」の正本）、権限チェック（足りない時だけ＝後出し済み）、テンプレ（初回の主行為を助ける）、FAB「＋ つくる」、使い方への導線
- ウィザード：ステップチップ（現在地）、きっかけ/やることの選択行、時刻チップ、文の入力欄（選択時のみ）、条件チップ＋範囲の説明（差分情報）、できあがりチップ列（プレビューの正本）、保存できない理由（エラー時のみ）
- 残した detail（情報の追加があるもの）：Wi-Fi「家に着いたときなど」、ケーブル「充電中でも、抜けば動く」、ヘッドホン「有線のみ」、マナーモード「着信音を消す」、おやすみ「通知をぜんぶ止める」、音量「メディアの音量」、通知/声「好きな文で〜」

### ノイズ（消したもの）
| 項目 | 種別 | 判定 |
|---|---|---|
| ウィザードStep3プレビューの summary 文 | 重複（種類1） | 直上のチップ列と同内容。片方を消しても失う情報なし → チップ列を正本にして文を削除 |
| MacroTile の遅延注意 | 重複（種類1） | 同じ注意が4か所（タイル/テンプレ/ウィザード/使い方）に出現。正本はウィザード（作る場面）と使い方（困った場面）。タイルは「置いた後の常時表示」で最もノイズ化していた → 削除 |
| テンプレの「タップで追加」 | 無関係 | カード全体が押せることは見た目で自明。操作説明はノイズ → 削除 |
| ウィザード小見出し「自動化をつくる/編集」 | 無関係 | 直下のステップチップで現在地は伝わる → 削除 |
| 「音」グループの用語説明 | 重複（種類1） | マナーモード/おやすみの説明は各行の detail と同内容 → 行側を正本にして削除 |
| detail の言い直し 13件 | 重複（種類1） | 「時刻／決めた時刻になったら」など、ラベルの言い直しは削除（8件）、情報が残るものは短縮（5件）。空になった行は detail 行自体を出さない |

### 短縮（ノイズではないが文字を減らしたもの）
- 遅延説明3種（電池/Wi-Fi/アプリ起動で文面バラバラ）→「約15分ごとにチェックするので、少し遅れて動きます」に統一
- 空状態の説明文：2文＋励まし → 1文に

## 数値（要素グループ単位の概算）
- 棚卸し項目：約60（全5画面＋ダイアログ）
- 消した表示：18件（ノイズ率 約30% → 0%：残った全項目に判定文か助け先が付く）
- 据え置きと判断したもの：オンボーディングの大きな番号タイル（1ページ1主張の主役＝演出であり情報ではない）、使い方の3ステップ再表示（見返しに来た場所＝重複の例外）、タイルの「オン/オフ」文字（スイッチの意味の補足＋色だけに頼らないため）

## 検証
- 重複テスト：遅延注意の出現箇所 4→3（テンプレは追加判断の場面として差分を残置＝例外として記録）、プレビューの二重表示は解消
- コンセプト照合：残項目すべてに必須の判定文または支援の助け先あり
- 人間での3秒/無読テストは未実施（実機待ち行列）。実機で最初に確かめる項目：ウィザードStep3でチップ列だけで内容が伝わるか
