# Phase 1（v1.8.0）きっかけ拡充 ― 実装設計メモ（2026-11-22 先行準備・未着手）

本人の開始判断（ボタン選択）が出たら、このメモからそのまま実装に入れるよう、Phase 1 の各きっかけについて Android での実現方式・権限・方式（即時/周期）を先に固めたもの。正本ロードマップは docs/ROADMAP_PARITY.md。

## ジャンルまとめUI（最初にやる土台）
- ウィザード Step1 を「ジャンル見出し → 中身が開く」段階表示に変える。ジャンルは7つ：時刻／場所／つながり／充電・電池／アプリ／連絡／端末の状態。
- 既存7種の TriggerType は enum のまま増やす（保存形式は name 文字列なので互換は保てる）。ジャンルは enum に group フィールドを追加（ActionType と同じ方式）。
- MacroTile・テンプレ・使い方の表記はジャンル導入後も現行のまま（名前＋要約で足りる）。

## 新きっかけ10件の実現方式
| きっかけ | 方式 | 権限 | 即時性 | 備考 |
|---|---|---|---|---|
| 時刻：曜日指定 | 既存の正確なアラーム＋発火時に曜日判定して再登録 | 既存 | 即時 | param に曜日ビットを足す（例 "22:00|1234567"）。旧形式 "22:00" は毎日として互換読み |
| 日の出・日の入り | 位置から太陽計算（標準アルゴリズム、APIキー不要）→ 時刻きっかけとしてアラーム登録 | 位置（概略で可） | 即時 | 毎日再計算して翌日分を登録。位置が無い時は概略位置/手入力の代替を用意 |
| 場所：着いたら／離れたら | Play Services Geofencing API | 位置（常時）＋バックグラウンド位置 | 即時 | 半径は既定150mに固定（選択肢を増やさない）。場所は地図ではなく住所検索＋現在地ボタンで1点だけ登録 |
| Bluetooth接続 | ACTION_ACL_CONNECTED 受信（接続機器のアドレスで判定） | BLUETOOTH_CONNECT（Android 12+） | 即時 | 対象はペアリング済み機器から1つ選ぶ。車のBluetooth＝CarPlay代替もこれ |
| 集中モード | ACTION_INTERRUPTION_FILTER_CHANGED 受信 | 既存（DNDアクセス） | 即時 | ON/OFF 両方向。既存の MissingPermRows に行を追加 |
| 省電力モード | ACTION_POWER_SAVE_MODE_CHANGED 受信 | なし | 即時 | ON/OFF 両方向 |
| 機内モード | ACTION_AIRPLANE_MODE_CHANGED 受信 | なし | 即時 | ON/OFF 両方向 |
| 通知が来たら | NotificationListenerService | 通知アクセス | 即時 | アプリ1つ＋キーワード（任意）で判定。メール/メッセージ/支払い通知は全部これで近似。新規の権限行と案内が必須 |
| アプリを閉じたら | 既存の UsageStats 周期走査で「前回 前面だったアプリが前面でなくなった」を検出 | 既存（使用状況） | 約15分 | 開いたらと同じ走査で同時に判定（二重発火防止は lastRunAt 流用） |
| 電池が増えたら | 既存の電池周期チェックに crossing 逆向きを追加 | なし | 約15分 | batteryCrossed の逆。Logic に単体テスト追加 |

## 実装の順番（推奨）
1. ジャンルUI＋group フィールド（見た目の土台）
2. 方式が軽い順：電池が増えたら → 集中/省電力/機内（ブロードキャスト3兄弟） → アプリを閉じたら → 曜日指定
3. 通知が来たら（リスナーサービス新設＋権限案内）
4. Bluetooth（機器選択UIが要る）
5. 場所（ジオフェンス＋場所登録UIが一番重い）
6. 日の出・日の入り（太陽計算＋毎日の再登録）

## リスク・注意
- 通知アクセスと位置（常時）は Play の申告対象権限。ストア提出時に用途説明が要る（素材パックの申告材料更新とセット）。
- ジオフェンスは端末の位置設定が OFF だと動かない → 権限チェックに「位置がオフ」を足す。
- ブロードキャスト系はマニフェスト登録で受けられるもの（機内・省電力）と、アプリ生存中のみのものがある。確実に受けるため、既存の充電レシーバーと同じマニフェスト登録方式で統一し、APK 実物で登録を確認する（v1.5.1 の教訓）。
- バージョンは v1.8.0 / versionCode 26。単体テストは Logic 追加分（電池逆crossing・曜日判定・太陽計算）を足す。
