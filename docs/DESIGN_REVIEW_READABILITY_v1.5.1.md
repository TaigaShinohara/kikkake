# 読みやすさ厳格レビュー（v1.5.1、2026-11-20）

本人の実機スクリーンショット（ダークモード、ホーム画面）をピクセル実測して判定した。判定：**不合格**。下地と文字色に構造的な欠陥がある。

## 実測値（スクリーンショット 917×2048）
- 背景の明るさ：左側 (123,63,86) ／ 右側 (41,37,39) — 同じ高さで約3倍の差
- カードのタイトル文字：(0,0,0) 純粋な黒
- アプリ名・履歴の文字：(255,253,242) 白 — 明示色の文字は正しく出ている

## 指摘
- **R-1（致命的）背景に「壁」がある**：画面の左6割だけが濃いマゼンタで、右はほぼ黒。縦の境界がカードを横切る。原因は2つ。(a) 光を Modifier.blur で描いており、ぼかしがレイヤーの端で切り捨てられて硬い縁になる。(b) ダーク側の光の色（#6A2440 等）が濃く彩度が高い。ガラスの大前提「下地は均一」が崩れているため、同じカードでも左と右でコントラストが変わる。ゲート1・2不合格。
- **R-2（致命的）カードのタイトルが真っ黒**：色を指定していない Text がテーマ既定色に流れ、ダークモードで黒 (0,0,0) に落ちている。「充電お知らせ」「テスト」という一番大事な名前が一番読めない。明示色を持つ文字（履歴・アプリ名・チップ）は正しく白／ピンクで出ており、既定色任せの文字だけが沈んでいる。同種の既定色 Text はウィザード・ダイアログ・許可行・テンプレ見出し等にも多数ある。ゲート1・7不合格。
- **R-3（重大）光が主役を食っている**：ダークの光が原色寄りで強く、色配分「地7」が守れていない。カード（読み物ガラス）が背景の主張に負けて輪郭が弱い。ゲート8不合格。
- **R-4（中）ボタン行が崩れている**：「削除」ボタンが幅不足で縦長の楕円に潰れ、文字が縦に積まれている。3ボタンが幅を取り合っている。ゲート6不合格。
- **R-5（中）FAB が履歴に被る**：「最近の実行」の最終行が「＋つくる」ボタンの裏に隠れる。リスト下部の余白不足。ゲート6不合格。
- **R-6（軽微）スイッチのつまみが濃紫**：オン状態でも暗い色で、状態が読み取りにくい。
- チップ行が右端で切れる点は、横スクロールの存在を示すサインにもなっており、今回は様子見とする（記録のみ）。

## 対処（v1.5.2）
- R-1/R-3：土台を作り直し。光は blur をやめて放射グラデーション（中心→透明）で描き、縁が切れないようにする。ダークの光は彩度と明度を落とす。基底グラデーションの段差も小さくする。
- R-2：全ての Text に Palette の明示色を付け、テーマ既定色に任せない。入力欄のラベル色も明示する。
- R-4：カードの3ボタンに均等な幅（weight）を割り当てる。
- R-5：リストの下部に 96dp の余白を追加。
- R-6：スイッチのつまみを白に統一。
- 教訓：①blur は大きな面のぼかしに使わない（端で切れる）。②文字色は全て明示する（既定色はモードで化ける）。③ダークの光は「淡色ティント」の原則どおり弱くする。

## 解消記録（v1.5.2、2026-11-20）
- R-1/R-3：AppBackground を作り直し（放射グラデーションの光＋基底の段差縮小、ダークの光 #6A2440→#4E2438 等に弱体化）。
- R-2：既定色だった Text 19箇所すべてに明示色を付与。入力欄はラベル色・入力文字色も colors で明示。残る既定色 Text はなし（ラベルはフィールド色で担保）。
- R-4：カードの3ボタンに weight(1f) を割り均等幅に。
- R-5：ホームのリスト下部に 96dp の余白。
- R-6：スイッチのつまみを白に統一。
- ゲート自己点検：1（コントラスト）はコード上の色値からは合格見込みだが、最終確認は実機の見え方でのみ可能（実機待ち行列）。2〜12はコード照合で合格。
