# 全体見やすさ監査（v2.2.2 向け・2026-11-22）

本人の指示「別途アプリ全体を見やすくする工夫もしてね」を受けた監査。v2.2.1（スクショ起点3件）の続き。
基準は Simple Glass 読みやすさパッケージ（本文14sp以上・行間1.6・補助文字コントラスト4.5:1）と実機スクショ。

## 現状の棚卸し（コード実測）
- 文字サイズ分布：15sp が中心、13sp が多数（補助テキスト）、12sp は2か所だけ。
- ホーム履歴・使い方・ウィザード選択肢の本文は 15sp／行間24sp で基準を満たす。
- ウィザード下部ボタン（もどる／次へ／保存）は正規ボタンで 15sp、問題なし。
- ダーク側の補助文字 #D8CFC2 は正本どおりで十分なコントラスト。色は触らない。

## 直す（v2.2.2）
1. **12sp をなくす**：使い方画面の例チップ（12sp）と AI 設定ダイアログの注記（12sp）を 13sp へ。
2. **グループ見出しを 13sp → 14sp**：ウィザードの「きっかけ」「やること」のグループ見出し（InkSoft）。小さい灰色文字が一番読みにくい場所だった。
3. **タップ領域を広げる**：
   - マクロタイルの操作行（テスト／編集／削除）：縦 padding 4dp → 8dp。
   - オンボーディングの「← もどる」：13sp → 14sp、padding 4dp → 8dp。
   - ホーム上部のリンク（書き出し／読み込み／使い方）：縦 padding を 8dp → 10dp 相当に。
4. **行間を 1.6 に寄せる**：タイル要約とテンプレカード要約の lineHeight 19sp → 21sp（13sp に対して約1.6）。

## 触らない（判断つき）
- タイル要約の文字サイズ自体（13sp）：2列タイルの密度とのバランスで意図的。行間だけ広げる。
- 色・グラスの質感：Simple Glass 正本のまま。今回のスクショでも破綻はない。
- レイアウト構造：ホーム／ウィザードの組み立ては変えない（v2.2.1 の修正で十分）。
